### 🏢 [Manpower Recruitment Platform: Backend](https://github.com/biswash12-stac/Manpower-project)

Production-ready backend for a manpower recruitment platform.

- 🔐 **JWT authentication** with secure token-based sessions
- 🛡️ **Role-based access control** (Super Admin / Admin)
- 🗄️ **MongoDB + Mongoose** data layer
- ⚙️ Built on **Next.js 16 API Routes** and **TypeScript**
